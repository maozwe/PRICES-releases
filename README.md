# PRICES-releases

בן הזוג הציבורי של אפליקציית **מנוע חיפוש מחירונים**. שני תפקידים, ושום
דבר אחר לא שייך לכאן:

1. **מחירונים.** כל מה שנמצא תחת [`files/`](files) נקרא על ידי האפליקציה —
   תיקיות כתיקיות, קבצים כקבצים, בכל מבנה שתשים.
2. **נתוני חיפוש.** [`data/`](data) מכיל את אותם מחירונים אחרי פרסור, בפורמט
   שהאפליקציה מחפשת בו. הוא נבנה אוטומטית מ-`files/` ואין לערוך אותו ביד.

הריפו הזה ציבורי בכוונה: מי שפותח את האפליקציה באתר בנייה לא אמור להזדקק
לסיסמה, וגם לא לחיבור לרשת ארגונית. **שום דבר פרטי לא נכנס לכאן.** לא נתוני
פרויקטים, לא מסמכי לקוחות ולא סיסמאות.

## הוספת מחירון

גרור אותו לאיזו תיקייה שתרצה תחת `files/`, בכל מבנה תיקיות. אפשר ישר מממשק
הווב: פותחים `files/`, ואז **Add file → Upload files**.

מרגע הדחיפה, workflow עושה שני דברים:

* מייצר מחדש את `index.json` — עץ הקבצים שהאפליקציה מציגה
* מריץ את הפרסרים ומעדכן את `data/` — הסעיפים שאפשר לחפש בהם

תוך דקה או שתיים המחירון החדש מופיע באפליקציה, בלי גרסה חדשה ובלי התקנה.

## פורמטים נתמכים

| סיומת | מה קורה |
|---|---|
| `.xlsx` `.xls` `.xlsm` | נקרא בפרסר אקסל. שורת הכותרת מאותרת לפי תוכן ולא לפי מספר שורה, כך שמבנים שונים נקראים בלי שינוי קוד |
| `.pdf` | נקרא לפי גיאומטריית עמודות. מותאם לפורמט של מחירון משרד השיכון; PDF במבנה שונה עשוי לדרוש התאמה |
| אחר | מופיע בעץ הקבצים אך לא נכנס לחיפוש |

קובץ שלא הצליח להיקרא אינו נעלם בשקט — הוא מדווח ב-`data/sources.json` תחת
`failed`, עם הסיבה.

## שם וגרסה של מחירון

`tools/sources.json` נותן שם תצוגה וגרסה למחירונים המוכרים, לפי שם הקובץ.
מחירון שאינו רשום שם ייקרא בכל זאת, ושמו יגזר משם הקובץ — כך שהכשל האפשרי
הוא שם פחות יפה באפליקציה, ולא מחירון חסר. כדי לתת לו שם נאה, הוסף ערך
ב-`tools/sources.json`.

## מבנה

```
files/               המחירונים כפי שהם. כאן אתה מעלה
index.json           עץ הקבצים — נוצר אוטומטית, לא לערוך
data/                הסעיפים אחרי פרסור — נוצר אוטומטית, לא לערוך
  sources.json       רשימת המחירונים, ספירות, ומה שלא נקרא
tools/
  build_index.py     files/ -> index.json
  build_data.py      files/ -> data/*.json, מזהה מחירונים לבד
  parsers/           פרסר אקסל, פרסר PDF, ותיקון עברית הפוכה
```

הקוד של האפליקציה והאתר יושב בריפו הפרטי `maozwe/PRICES`.
